## Учёт картриджей
Система учёта и выдачи картриджей для оргтехники с графическим интерфейсом (Tkinter) и консольной версией.

## Возможности
Добавление новых картриджей (серийный номер, модель)

Выдача картриджа сотруднику/подразделению

Возврат картриджа на склад

Просмотр всех картриджей с фильтрацией

Автоматическая фиксация даты выдачи

Сохранение данных в JSON-файл

Расширенная отчётность:

Фильтрация по месяцам

Фильтрация по подразделениям

Сохранение отчёта в файл

Копирование отчёта в буфер обмена

## Технологии
Язык: Python 3

GUI: Tkinter / ttk

Хранение данных: JSON

Стандартные библиотеки: json, os, datetime, collections

## Установка и запуск
Убедитесь, что установлен Python 3.6+

Скачайте файлы проекта

Запустите графическую версию.
Структура файлов
Файл	Описание
main.py	Основная программа с графическим интерфейсом (Tkinter)
console.py	Консольная версия для работы в терминале
cartridges.json	Файл базы данных (создаётся автоматически)
Интерфейс
Графическая версия
Добавить — новый картридж на склад

Выдать — выдать картридж выбранному подразделению

Вернуть — вернуть картридж на склад

Обновить — обновить таблицу

Отчёт — расширенная статистика с фильтрацией

Консольная версия
Меню с пунктами:

Добавить картридж

Выдать картридж

Вернуть картридж

Показать все картриджи

Выход

Бух, Склад сырья, ООПП, КомОт, ПЭО, ОтВалидации, Технологи, АУП, Испыт центр, ООК, ОКК, КАЛаб, Окадр, ОхТр, Водоподг, ОИР, Цех1–6, Другое
